# MELTDOWN — 기획서

> 상태 표기
> - **확정**: 논의에서 결정된 사항
> - **제안**: 논의 중 나온 제안으로, 아직 명시적으로 확정되지 않은 사항
> - **예시**: 감을 잡기 위한 예시. 실제 목록은 추후 결정

---

## 1. 개요 (확정)

| 항목 | 내용 |
|---|---|
| 장르 | 실시간 + 일시정지 로그라이크 |
| 플레이어 | 원자력 발전소 제어실 운전원 |
| 한 판 | 위기(사고) 하나를 수습하는 것 |
| 실패 | 멜트다운 |
| 성공 | 안정화 (엔딩 두 갈래, 4장 참고) |
| 점수 | 발전량 |
| 한 판 길이 | 기본 10~20분, 어려운 원자로·높은 난이도에서는 30~40분 |
| 빌드 요소 | 모듈 빌딩 (슬더스의 카드에 해당) |
| 캐릭터에 해당 | 원자로 종류 (6종) |
| 판과 판 사이 | 슬레이 더 스파이어식 |
| 비주얼 | 레트로 산업 공포풍 픽셀아트 콘솔 |
| 기술 | TypeScript |

### 핵심 딜레마

> 안전하게 가려면 출력을 내려야 하고, 점수(발전량)를 얻으려면 출력을 유지해야 한다.

## 2. 한 판의 흐름

### 2.1 위기의 성장 (확정)

- 위기를 키우는 것은 **사고 원인**이다. 원인은 판마다 다르다.
- 사고 원인이 해결되지 않은 동안 위기 단계가 올라가고, 설비 마모와 연쇄 고장 확률이 커진다.
- 원인이 많을수록 위기는 빠르게 커진다.
- **연쇄 고장이 새 사고 원인을 만든다.** 하나를 고치는 사이 원인이 한 번에 둘 이상 생길 수도 있다.
- 따라서 안정화를 미루며 발전량을 쌓는 꼼수는 구조적으로 막힌다. 미룰수록 원인이 불어난다.

### 2.2 연쇄 고장 (확정)

- 모든 설비는 **내구도**를 가진다.
- 무리한 운전과 위기 단계에 따라 내구도가 닳고, 내구도에 따라 고장 확률이 정해진다.
- 그래서 다음에 어디가 고장 날지 확정적으로 알 수 없다.

### 2.3 공정성 장치 (제안)

연쇄가 눈덩이처럼 불어나도 "내 판단 때문에 졌다"고 납득할 수 있게 하는 장치.

- **고장 징후**: 내구도가 낮은 설비는 고장 전에 진동, 소음, 경고등 깜빡임 같은 신호를 낸다. 높은 난이도에서는 이 신호도 거짓일 수 있다.
- **전파 경로의 가시화**: 고장이 어느 계통으로 번지는지 보이게 한다. 예: 펌프 고장은 냉각 계통, 터빈 고장은 압력 계통.
- **사고 보고서**: 판이 끝나면 어떤 고장이 무엇을 불렀는지 연쇄 과정을 보여 준다.

### 2.4 보급 (확정)

- **시점**
  - 위기 단계가 오를 때
  - 고비를 넘겼을 때 (사고 원인 해결, 연쇄 고장 수습)
- **방식**: 모듈 3개 중 1개를 골라 패널에 설치한다.

---

## 3. 점수 (확정: 발전량)

- 점수는 한 판 동안의 **발전량**이다.
- 하이 리스크 하이 리턴 모듈의 "리턴"도 발전량이다.
- (제안) 원자로 위험도와 난이도 단계에 따라 **점수 배율**을 준다.
- (제안) 점수가 **해금 진행도**로 이어진다 (슬더스식).

---

## 4. 안정화 조건 — 엔딩 두 갈래 (확정)

| 엔딩 | 조건 | 점수 |
|---|---|---|
| **운전 중 안정화** | 모든 사고 원인을 해결한 뒤, 일정 출력 이상을 유지하며 모든 수치를 안전 범위에 일정 시간(예: 60초) 유지 | 높음 |
| **냉온 정지** | 원인 해결 여부와 관계없이 원자로를 멈춰 노심 온도를 기준 이하로 일정 시간 유지. 정지 후에도 잔열이 나오므로 냉각은 계속 필요 | 낮음 |

판이 꼬였을 때 "점수는 포기하고 살아남자"는 선택지를 주는 것이 목적이다.

> 미정: 출력 기준, 유지 시간, 냉온 정지 온도 기준 등 구체적인 수치

## 5. 모듈 빌딩

### 5.1 기본 규칙 (확정)

- 슬더스의 카드에 해당한다. 덱 빌딩이 아니라 **모듈 빌딩**.
- **시작 모듈은 무작위**로 주어진다. 그래서 패널 구성이 판마다 다르다.
- 판 도중 **보급**으로 모듈을 추가한다.
- 일부 모듈은 판을 거듭하며 **해금**된다.
- 예: 거짓 계기의 **오차 범위를 알려 주는 장치**

### 5.2 하이 리스크 하이 리턴 모듈 (확정: 반드시 존재)

슬더스의 보스 유물처럼, 강력하지만 대가가 확실한 모듈.

| 모듈 (예시) | 리턴 | 리스크 |
|---|---|---|
| 안전 연동장치 해제 키 | 제어봉을 한계 이상으로 빠르게 조작 | 자동 비상정지 비활성화 |
| 과부하 냉각 펌프 | 냉각 능력 대폭 증가 | 내구도가 빠르게 닳고, 고장 시 주변 설비까지 손상 |
| 시제품 자동 제어기 | 온도 자동 추종 | 일정 확률로 오작동하며, 그때 계기 수치가 거짓으로 바뀜 |
| 비공식 우회 배관 | 압력 즉시 대폭 감소 | 방사능 누출로 이후 보급 질 하락 |
| 제논 강제 연소 | 막힌 출력 즉시 회복 | 몇 초간 출력이 예측 불가능하게 출렁임 |

### 5.3 원자로 전용 특수 모듈 (확정)

- 가압경수로를 **제외한** 5종에만 존재한다.
- 판마다 나올 수도, 안 나올 수도 있다.
- **보급에서만** 나온다.
- 일부는 해금 대상이다.

## 6. 원자로 6종 (확정: 원자로 종류가 캐릭터 역할)

위험도 순서 (낮음 → 높음). 용융염로는 실제 위험도가 아니라 **플레이 난이도** 기준으로 4위에 두었다.

| 순서 | 원자로 | 게임에서의 성격 | 특수 모듈 (예시) |
|---|---|---|---|
| 1 | **가압경수로 (PWR)** | 냉각이 줄면 출력도 스스로 줄어드는 자기 안정성. 입문용 | 없음 |
| 2 | **비등경수로 (BWR)** | 노심 안에서 물이 바로 끓어 압력·증기·출력이 함께 출렁임 | 재순환 펌프 제어기 (유량으로 출력 조절), 압력억제수조 |
| 3 | **중수로 (CANDU)** | 냉각이 줄면 출력이 살짝 오름. 연료 채널이 많고 운전 중 연료 교체 | 운전 중 연료 교체기, 독물질 주입 장치 (2차 정지 수단) |
| 4 | **용융염로 (MSR)** | 액체 연료. 배출 밸브를 여는 시점, 배출 후 잔열, 부식 관리 | 동결 마개 수동 해제기, 오프가스 장치 (제논 제거) |
| 5 | **소듐냉각 고속로 (SFR)** | 반응 속도가 빠르고, 소듐이 새면 화재. 사고가 사고를 부름 | 아르곤 소화 설비, 전자기 펌프 |
| 6 | **RBMK (체르노빌형)** | 냉각이 줄면 출력 폭주. 제어봉을 넣는 순간 출력이 튀는 결함 | 개량형 제어봉, 붕소 투하 |

- (제안) 처음에는 가압경수로만 열려 있고, 순서대로 해금된다.

## 7. 난이도 (확정)

- 슬더스의 승천처럼 **난이도 단계**가 있다.
- **거짓 계기**: 쉬움에서는 없고, 단계가 올라갈수록 늘어난다.

> 미정: 단계 수, 단계별로 누적되는 불리한 조건 목록

## 8. 판과 판 사이 — 슬더스식

| 요소 | 상태 | 내용 |
|---|---|---|
| 영구 능력치 성장 없음 | 제안 | 운전원이 강해지지 않음. 플레이어의 이해가 진짜 성장 |
| 해금으로 선택지 확장 | 확정 | 새 모듈, 특수 모듈 등이 판을 거듭하며 풀림 |
| 난이도 단계 해금 | 확정 | 승천식 |
| 원자로 종류 = 캐릭터 | 확정 | 6종 |
| 시작 보너스 선택 | 제안 | 슬더스의 니오의 축복. 출근 전 브리핑에서 보너스나 대가를 고름 |
| 기록·도감·일일 도전 | 제안 | 사고 보고서, 통계, 설비 도감, 같은 시드로 겨루는 일일 사고 |
